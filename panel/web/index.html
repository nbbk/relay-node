添加落地

默认走 80：落地机装节点时用 80 端口验证域名签证书，最常用、不用多配；代价是 80 必须直通落地，改了监听端口或域名指着中转时，续签要手动把域名改回指向落地。DNS 验证：落地机用 Cloudflare 令牌在 DNS 里加验证记录签证书，续签全自动，域名指哪都行、不用 80；前提是装节点时选了 DNS 验证并配好令牌，没配令牌的落地别选这个。

    订阅对外域名

    填了之后，面板里所有订阅链接都改成 https://这个域名/…，不再显示面板自己的地址。

    选填，留空就用面板自己的地址（IP:端口）。部署完 Cloudflare Worker、想让订阅走 Worker 域名时再填 Worker 的域名。

    对外域名详细说明填了之后，面板里所有订阅链接（通用链接、每人链接、合并订阅、二维码）都改成 https://这个域名/sub/…，不再显示面板自己的地址；留空保存就恢复成面板自己的地址。只填域名（可带端口），不用写 https://，不用写路径。Worker 代码里的源站地址不受影响，仍是面板真实地址。

    订阅路径

    默认是 /sub/，想让订阅链接更不像机场就改成别的单段路径。

    /

    默认是 /sub/。改路径后面板重启、要重新登录，旧订阅链接全部失效、客户端须重新导入。

    订阅路径详细说明想让订阅链接更不像机场，就改成别的单段路径（例如 x9f2，链接变成 https://域名/x9f2/<令牌>）。Worker 反代代码也要按新路径重新生成、重新部署。路径只允许字母开头、字母数字与 - _、1–32 个字符；api 与 logo 是保留段，不能用。留空保存 = 恢复默认 sub。

    Worker 反代（防封订阅）

    订阅链接直接由面板出时，客户端看到的是面板真实地址；套一层 Cloudflare Worker 反代后，客户端只看到 Worker 自己的域名，面板真实地址只出现在 Worker 代码里（你的 Cloudflare 账号内可见）。部署后把订阅链接里的面板地址换成 Worker 地址，令牌和参数都不变。

    选填，留空就用你现在打开面板的地址（IP:端口），直接能用；Worker 反代是可选项，只有想藏面板 IP、走 HTTPS 订阅时才需要配域名。如果面板对外是另一个地址（例如绑了域名、走了反代），填那个地址再生成；填一次就记住，下次打开自动填上。源站地址必须是域名、不能是 IP（Worker 的 fetch() 不能直接用 IP 回源，会报 Cloudflare error 1003）；必须是 http:// 开头（面板是明文 HTTP，没有 HTTPS）。源站地址只出现在 Worker 代码里（你的 Cloudflare 账号内可见），客户端看不到面板真实地址。

    
              
    
                
              
    
              
    部署步骤：Cloudflare 后台 → Workers → 新建 Worker → 粘贴代码 → 部署；可选在触发器里绑一个自定义域名。部署后订阅链接 = https://<Worker 域名>/sub/<令牌>，其余参数不变。Worker 免费额度够订阅拉取用（每天少量请求）。

    总量与按月是两种算法；与到期时间是“或”的关系，哪个先到节点就停用。续期只延长时限、续量只补流量。
    
          
    
            
    
              
    
              
    
              
    
            
    
            
    
              
              
              
            
    
          
    
        
    
      
    

      
      
    
        
    集中管理
    
        
    一台主面板管多台远程面板：登记远程面板后，每台面板一张卡片，卡片上能看到在线状态、版本、落地数、流量汇总（各落地已用/上限合计）与最近到期时间；点卡片的“查看详情”弹出该面板的落地与节点详情（状态、证书、每个落地的到期与流量），详情按需加载。卡片上还能直接代理远程面板的全部中转与节点操作：加/编辑/删除落地、加/删节点、续期、流量设置与续量、证书、远程体检与一键修复、重启 realm、看链接、订阅。实时日志不代理，要看日志点“打开远程面板”跳过去。没登记任何远程面板时，本面板的行为与原来完全一致。
    
        
    
          
    
            
            
            
          
    
          
    
            
    已登记的远程面板
    
            
    
            
    
          
    
          
    
            
    登记远程面板
    
            
    先到被管面板的设置页“远程管理令牌”卡片里生成令牌，再把地址和令牌填进来。令牌只保存在主面板的配置文件里（600 权限），不会显示出来。登记时会当场连一次，连不上、令牌不对或远程面板版本太旧（低于 1.2.0）都会直接拒绝并写清原因。
    
            
    
              
    
                
    
                
    
                
    
              
    
              
    
            
    
          
    
          
    
            
    合并订阅
    
            
    按落地勾选，生成一条合并订阅链接：一个链接导入，客户端一次拿到选中落地的节点（下面能选只要中转或只要直连）。勾面板即选它下面全部落地，部分选时面板框显示半选；顶上可全选全部面板。每个落地行上还有“复制订阅”，只导这一个落地的节点。内容实时生成，面板里增删节点后自动跟着变；勾选变了就重新生成一条，不同选择各用各的令牌。
    
            
    加载中…
    
            
    
              
              
              全部：中转和直连的节点都进订阅；仅中转：只要走中转机的节点；仅直连：只要直连落地机的节点。
            
    
            
    
            
    到期留空 = 永久；填日期 = 当天 23:59:59 到期，到期后这条订阅打不开。
