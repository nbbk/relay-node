添加落地

默认走 80：落地机装节点时用 80 端口验证域名签证书，最常用、不用多配；代价是 80 必须直通落地，改了监听端口或域名指着中转时，续签要手动把域名改回指向落地。DNS 验证：落地机用 Cloudflare 令牌在 DNS 里加验证记录签证书，续签全自动，域名指哪都行、不用 80；前提是装节点时选了 DNS 验证并配好令牌，没配令牌的落地别选这个。

提交后面板会先预检端口；若 80 / 443 已被占用，会弹出方式选择（改监听走高位端口、按域名分流、按 SNI 分流等）。

    面板端口

    改端口后面板会重启自身，请用新端口重新打开（原页面会断开）。

    IP 白名单

    只允许这些 IP 访问面板。留空 = 不限制。白名单外的 IP 访问任何接口都会返回 403。

    HTTPS

    无域名时生成自签证书（浏览器首次会提示一次，点继续访问即可）；绑域名后自动申请真证书（DNS 验证，不占 80 端口）。

    Cloudflare Token

    绑域名开 HTTPS 时用它签证书（DNS 验证）。只用 IP 访问（自签证书）不用填。令牌怎么开见仓库里的 CLOUDFLARE_TOKEN.md。

    任意门地址

    任意门链接用这个地址生成；改完历史记录里的任意门链接自动跟着改；留空清除则下次加任意门落地时自动探测。

    Telegram 提醒

    证书快到期、中转挂了、落地到期或流量用完时自动发消息。需要 Bot Token 和 Chat ID。

    机器监控告警

    每 5 分钟采样一次磁盘、内存与 CPU，超阈值时总览页标红（严重）/标黄（警告），并走上面配好的 Telegram 提醒；没配 Telegram 就只在面板里标色，不报错。同一指标越过阈值只提醒一次，持续超标每小时最多再提醒一次，回落到阈值以下后恢复，下次再越过重新提醒。

    延迟探测

    后台定时对每个落地做 TCP 连接测延迟：只做 TCP 握手，不发任何应用层数据，不会干扰 TLS / Xray。探测目标是落地地址:落地端口（中转配置里的转发目标），不是中转机本地监听端口，所以能真实反映落地在线与否；任意门模式的落地同样探测。离线时总览卡片标红，并走上面配好的 Telegram 提醒（同一落地离线只提醒一次，持续离线每小时最多一次，恢复后报恢复）；没配 Telegram 就只在面板里标红。延迟只显示毫秒数，不做高低判定，避免误判。

    超时固定 3 秒，不可改；结果存在面板自己的 latency.json 里，重启面板不丢。

    远程管理令牌

    允许另一台主面板通过令牌管理本面板（看状态、加/删落地、看链接、重启 realm）。令牌只存哈希，生成时明文只显示一次，记下来，关掉页面就再也看不到了。改密码、改端口等设置接口令牌调不通。轮换后旧令牌立即失效；撤销后任何主面板都连不进来。

    集中管理

    一台主面板管多台远程面板：登记远程面板后，这里能看到每台的在线状态、版本、落地数与磁盘使用率，还能直接代理加落地、删落地、看链接、重启 realm。没登记任何远程面板时，本面板的行为与原来完全一致。

    登记远程面板

    先到被管面板的设置页“远程管理令牌”卡片里生成令牌，再把地址和令牌填进来。令牌只保存在主面板的配置文件里（600 权限），不会显示出来。登记时会当场连一次，连不上、令牌不对或远程面板版本太旧（低于 1.2.0）都会直接拒绝并写清原因。
