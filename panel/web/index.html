添加落地

默认走 80：落地机装节点时用 80 端口验证域名签证书，最常用、不用多配；代价是 80 必须直通落地，改了监听端口或域名指着中转时，续签要手动把域名改回指向落地。DNS 验证：落地机用 Cloudflare 令牌在 DNS 里加验证记录签证书，续签全自动，域名指哪都行、不用 80；前提是装节点时选了 DNS 验证并配好令牌，没配令牌的落地别选这个。

    分组（权限组）

    一组 = 一组落地 + 一组用户，组里的人用组里的节点。建一次组、加用户就行，不用每人重复勾落地；通用共享节点放一个组，美国/英国/法国等定制用户各放各的组。改组的落地，组里所有人的订阅下次更新立即同步，链接不变；删组后成员恢复自己原来勾的落地，链接也不变。

    分组只决定用户能看到哪些落地，限流还是按人单独算（组里开了限流的人各走自己的独立转发端口，互不干扰）。

    每用户端口段

    开了限流的订阅，每人每台中转机上占一个独立监听端口（从这个段里分配）。默认 30000–39999。

    已分配的转发不受影响（端口照常工作，新分配才用新段）；段里撞上落地监听端口或面板端口时分配会自动避让。段满了会建不出新转发，报错里会提示扩段。

    中转倍率

    本台中转机的流量倍率，与单落地的倍率相乘：实际流量 × 落地倍率 × 中转倍率计入订阅用量（userinfo 与 80%/100% 限流都按折算后的用量算）。默认 1。

    空着 = 1（不加倍）。只设一处就只算那一处；改完才按新倍率算，之前已记的用量不追溯。管理面板本机没有中转，这张卡不显示，中转倍率由各中转面板自己设。

    导出 / 导入整机配置
    
            
    导出：所有落地、方式、设置打包成一个 JSON 文件。设了异地备份口令后，导出文件还含订阅令牌与加密的迁移信封，换中转机导入就全回来了（恢复时要输口令）；没设口令的导出文件换机要逐个轮换令牌。改配置前面板自动拍的操作前快照（backups/）只是安全网，不能当迁移备份用。

    流量限制设置
    
          
    总量与按月是两种算法；与到期时间是“或”的关系，哪个先到节点就停用。续期只延长时限、续量只补流量。
    
          
    
            
    
              
    
              
    
              
    
            
    
            
    
              
              
              
            
    
          
    
        
    
      
    

      
      
    
        
    集中管理
    
        
    一台主面板管多台远程面板：登记远程面板后，每台面板一张卡片，卡片上能看到在线状态、版本、落地数、流量汇总（各落地已用/上限合计）与最近到期时间；点卡片的“查看详情”弹出该面板的落地与节点详情（状态、证书、每个落地的到期与流量），详情按需加载。卡片下面展开“节点”子列表（节点名、健康、本期流量，点“详情”看节点详情、流量与健康），本机面板的节点也在同一页最上面可见。卡片上还能直接代理远程面板的全部中转与节点操作：加/编辑/删除落地、加/删节点、续期、流量设置与续量、证书、远程体检与一键修复、重启 realm、看链接、订阅。实时日志不代理，要看日志点“打开远程面板”跳过去。没登记任何远程面板时，本面板的行为与原来完全一致。
    
        
    
          
    
            
            
            
          
    
          
    
            
    已登记的远程面板
    
            
    
            
    
            
    
          
    
          
    
            
    登记远程面板
    
            
    先到被管面板的设置页“远程管理令牌”卡片里生成令牌，再把地址和令牌填进来。令牌只保存在主面板的配置文件里（600 权限），不会显示出来。登记时会当场连一次，连不上、令牌不对或远程面板版本太旧（低于 1.2.0）都会直接拒绝并写清原因。
